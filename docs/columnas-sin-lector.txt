#
# Esta lista es un TRINQUETE, no una lista de tareas: la guarda falla si
# aparece una columna nueva sin lector, y falla pidiendo bajar la marca si una
# consigue lector y nadie la saca de acá. No afirma que este estado esté bien
# — impide que empeore.
#
# Cada línea lleva su MOTIVO después de « — », y eso es a propósito: tener que
# escribir el porqué es lo que impide que la lista crezca sola. Un motivo que
# dice «pendiente» con su issue está bien; uno que no dice nada, no.
#
# `updated_at` queda fuera de la medición por regla, no por excepción: es una
# marca operativa que la plataforma mantiene sola y que ninguna pantalla
# muestra. Hay una por tabla de negocio, y diecisiete entradas diciendo lo
# mismo enseñarían a no mirar esta lista. `created_at` NO queda fuera: «desde
# cuándo existe esto» es información que el producto sí muestra.
#
# Se regenera con: node scripts/columnas-sin-lector.mjs --escribir
# (conserva los motivos que ya estaban; las nuevas quedan con SIN MOTIVO y la
#  guarda falla hasta que alguien escriba el porqué)
